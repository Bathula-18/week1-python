# Week 4 - Data Modeling

This week covers basic data modeling concepts used in data engineering and data warehousing.

Topics covered:
- Entities and Attributes
- Relationships
- Primary and Foreign Keys
- Grain Definition
- Fact and Dimension Tables
- Star Schema and Snowflake Schema
- Slowly Changing Dimensions (SCD)
- Medallion Architecture
- Bridge Tables
- OLTP vs OLAP concepts

Practice included:
- Business requirement understanding
- Schema design thinking
- Fact vs dimension identification
- Dashboard modeling concepts

Mini project:
Designed basic e-commerce warehouse model using fact and dimension tables.
