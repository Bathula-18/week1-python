# Week 2 SQL Practice

## Learning

This week I practiced core SQL concepts and improved my understanding of querying and reporting data.

### Topics Covered

- used SELECT and WHERE clauses to filter data
- practiced GROUP BY for aggregations
- used COUNT and SUM functions for reporting
- understood INNER JOIN and LEFT JOIN between tables
- practiced HAVING clause for grouped filtering
- handled NULL values using IS NULL and COALESCE
- used CASE statements for conditional logic
- practiced ORDER BY for sorting results
- created customer order summary reports using aggregations
- built a mini project report using LEFT JOIN and aggregations
